Suggested use

  1. 1

    Enter your draft

    Paste the short description you want to test and choose a Steam genre or tag that fits the game.

  2. 2

    Compare it with four games

    Your draft is shuffled with four descriptions from games under your selection. Titles and review counts stay hidden, and your draft is not marked.

  3. 3

    Ask other people to rank them

    Ask people to order all five by how much each makes them want to learn more.

  4. 4

    Revise against the same set

    Edit your description and use the same four games for the next ranking. Draw another set when you want different comparisons.

Your draft, card order and exclusions stay in this browser. Clearing site data removes them.
