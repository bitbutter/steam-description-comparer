A practical test for your Steam page

Find out how your game description holds up

Put your work-in-progress description into a mixed A–E line-up with four Steam games from the same genre, with the sources hidden. Then use other people's rankings to guide the next draft.

Start with your description

Suggested use

  1. 1

    Enter your draft

    Paste the short description from your work-in-progress Steam page and choose its genre.

  2. 2

    Compare it in context

    Your draft is shuffled into a random set with four descriptions from Steam games in that genre, without marking which is yours.

  3. 3

    Ask other people to rank them

    Copy the A–E list without its source information and ask people to order all five by how much each makes them want to learn more.

  4. 4

    Revise against the same set

    Edit your description and ask the same ranking question against the same four games. Resample when you want a fresh benchmark.

Use Resample Steam games for another set of games. Reveal information shows the Steam titles, review counts and Exclude buttons. You can restore excluded games in Settings.

Your description and exclusions are stored locally in your browser and aren't uploaded by this tool.
